# filip-pilar/tap

Homebrew formulae by filip-pilar.

```bash
brew install filip-pilar/tap/cleanpaste && brew services start cleanpaste
```

| Formula | What it does |
|---|---|
| [cleanpaste](https://github.com/filip-pilar/cleanpaste) | Strips tracking parameters from links as you copy them |

Formulae are updated by each project's release script.
